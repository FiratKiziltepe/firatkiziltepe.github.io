# Tablo Görüşler — bağımsız NAS sürümü

PHP 8.3 + MariaDB. Arayüz mevcut React uygulamasından korunmuştur.

Güncel kolay kurulum: [KOLAY-KURULUM.md](KOLAY-KURULUM.md).

Paket: **tablogorusler-nas-kolay.zip**. Paketin içindeki `tablogorusler/` klasörünü mevcut PHP web klasörüne yükleyin. Bağlantı: **baglan.php**, **mysqli**. SQL dosyasını phpMyAdmin'den içe aktarın; `setup.php` gerekmez.

Ana Supabase uygulamasında değişiklik yapılmaz. Canlı veriler ve kullanıcılar otomatik taşınmaz.
